## Como rodar

```bash
python3 01-saldo-bancario/solucao.py
```

O programa lê da entrada padrão. Digite os valores e pressione Enter; no Linux/macOS use `Ctrl+D` para encerrar, no Windows `Ctrl+Z` e Enter.

Para testar um caso do arquivo `entradas_exemplo.txt`, copie as linhas do caso depois do marcador `esperado:`.

Cada solução em Python 3 foi testada com os quatro casos de exemplo de `entradas_exemplo.txt` e produziu a saída esperada.
